# Ajay Stationary Shop Website

A responsive, static website for Ajay Stationary Shop, Rajendra Nagar West, Gorakhpur.

## Files
- `index.html` — website content and sections
- `style.css` — responsive design
- `script.js` — mobile navigation, WhatsApp enquiry buttons, current year
- `images/` — the four shop photos supplied for this website

## Run locally
Open `index.html` in a browser. For best results, upload the complete folder contents to a static host.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the complete `images` folder.
3. In repository Settings → Pages, choose the `main` branch and `/ (root)`.
4. Save and open the generated Pages URL.

## Before publishing
- Confirm the opening hours (currently marked estimated).
- Verify the phone/WhatsApp number, email, address, and map link.
- Product prices are not invented; the site asks customers to enquire on WhatsApp.
- This is a static showcase/enquiry website, not a payment-enabled online checkout.
